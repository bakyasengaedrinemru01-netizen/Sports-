EDRINE SPORTS WEBSITE + INSTALLABLE ANDROID PWA

This folder contains a responsive sports website and a Progressive Web App (PWA).
It can be installed on Android from a supported browser after it is hosted using HTTPS.

IMPORTANT:
- Match scores, fixtures, and league standings in this starter project are SAMPLE DATA.
- It does not connect to a live sports API and does not use Base44 monthly integrations.
- Do not describe sample scores as real-time scores.
- To add real live scores later, connect a permitted sports-data API and configure its key securely on a server.

PUBLISH:
1. Upload the contents of this folder to a static website host that provides HTTPS.
2. Open the published website in Chrome on Android.
3. Open Chrome menu (three dots).
4. Choose "Install app" or "Add to Home screen".
5. Follow the prompts. EDRINE SPORTS will appear as an app icon.

The PWA is installable; this package is not an APK file and is not yet published to Google Play.
